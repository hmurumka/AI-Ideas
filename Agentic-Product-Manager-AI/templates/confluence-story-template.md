# Confluence Story Template

Page Title: [Epic Name] → [Story Title]

Sections:

- Story Summary: Business context + technical scope.
- Acceptance Criteria: List of functional and non-functional acceptance items.
- Approval Checklist: Stakeholders + timestamps (use ../templates/approval-checklist.md for checklist items).
- Execution Agents:
  - Coding Agent → Repo commits / PR links.
  - Testing Agent → Test suite results (links to CI/CD runs).
  - Documentation Agent → Updated diagrams and notes.
- Dependencies: Component dependency graph snapshot (include link or inline mermaid image).
- Demo Notes: Screenshots, review feedback, and meeting notes.
- Audit Trail: Who approved (names), timestamps, change log.

Tips:
- Keep links to PRs, Confluence diagrams, and CI runs for traceability.
